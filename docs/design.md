The user will choose the options in main for the tasks they want to accomplish
Ex. 1. Enter temp.
    2. Change temp. range
    3. Calculate avg.
    4. Display readings & status
    5. Save readings & status

Once the tasks is chosen the program will call the respective functions to do such tasks.
Such example functions could be as such:
  void userReadings()
  int tempAvg(int readings[])
  void displayTemp(int readings[])
  void saveToFile(char* file);
